# 15 - Cloud Computing

## What is Cloud Computing?

Cloud computing is the delivery of computing services (servers, storage, databases, networking, software) over the internet. Instead of owning and maintaining physical data centers, you access technology services on demand from cloud providers like Microsoft Azure, AWS, and Google Cloud.

## Why Learn Cloud Computing?

- **Pay-as-you-go** — Only pay for what you use.
- **Scalability** — Scale resources up or down instantly.
- **Global reach** — Deploy applications in data centers worldwide.
- **Focus on code** — No need to manage physical hardware.
