# Exercise 01 — Cloud Fundamentals

## Objectives

- Understand what cloud computing is
- Learn the benefits of cloud over on-premise
- Identify real-world cloud usage examples

## What is Cloud Computing?

Cloud computing is delivering computing services (servers, storage, databases, networking, software, analytics) over the internet ("the cloud"). Instead of buying and maintaining physical data centers, you rent computing power and storage from providers like Azure, AWS, or Google Cloud.

## Key Benefits

| Benefit | Description |
|---------|-------------|
| Pay-as-you-go | Only pay for what you use, no upfront costs |
| Scalability | Scale resources up or down instantly based on demand |
| Global reach | Deploy applications in data centers worldwide |
| Reliability | Data backup, disaster recovery, and high availability |
| Security | Providers invest heavily in security measures |
| Speed | Provision resources in minutes instead of weeks |

## Types of Cloud Workloads

1. **Web hosting** — Host websites and web applications.
2. **Data storage & backup** — Store files, databases, and backups.
3. **Big data analytics** — Process large datasets using cloud computing power.
4. **AI & Machine Learning** — Train models using cloud GPUs.
5. **Dev & Test environments** — Spin up temporary environments for testing.
