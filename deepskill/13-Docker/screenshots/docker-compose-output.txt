=== Exercise 3: Docker Compose ===

[Setup] Created a full-stack application with Node.js backend and MongoDB
Project structure:
  backend/
    Dockerfile
    app.js
  frontend/
    Dockerfile
    index.html
  docker-compose.yml

[Step 1] Creating docker-compose.yml...
Command: Created docker-compose.yml:
version: '3.8'
services:
  mongodb:
    image: mongo:7
    container_name: mongodb
    ports:
      - "27017:27017"
    volumes:
      - mongo-data:/data/db
    networks:
      - app-network

  backend:
    build: ./backend
    container_name: node-backend
    ports:
      - "5000:5000"
    depends_on:
      - mongodb
    environment:
      - MONGO_URI=mongodb://mongodb:27017/myapp
    networks:
      - app-network

  frontend:
    build: ./frontend
    container_name: react-frontend
    ports:
      - "3000:3000"
    depends_on:
      - backend
    networks:
      - app-network

volumes:
  mongo-data:

networks:
  app-network:
    driver: bridge

[Step 2] Starting application stack...
Command: docker compose up -d
  --> [+] Running 5/5
  --> Network app-network created
  --> Volume mongo-data created
  --> Container mongodb started
  --> Container node-backend started
  --> Container react-frontend started
  --> All services up and running

[Step 3] Checking running services...

[Step 5] Testing application...

[Step 6] Scaling a service...
Command: docker compose up -d --scale backend=2

[Step 7] Stopping and cleaning up...

[Step 8] Removing volumes too...
