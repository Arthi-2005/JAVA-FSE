=== Exercise 2: Building Docker Images ===

[Setup] Created a simple Node.js web application
Files: app.js, package.json, public/index.html

[Step 1] Creating Dockerfile...
Command: Created Dockerfile in project root:
FROM node:18-alpine
WORKDIR /usr/src/app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["node", "app.js"]

[Step 2] Building first image...

[Step 7] Building optimized image with multi-stage...
Command: Created optimized Dockerfile with multi-stage build:
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production

FROM node:18-alpine
WORKDIR /usr/src/app
COPY --from=builder /app/node_modules ./node_modules
COPY . .
EXPOSE 3000
CMD ["node", "app.js"]

Command: docker build -t my-node-app:v2 .
  --> [+] Building 8.2s
  --> Successfully built 789def456abc
  --> Successfully tagged my-node-app:v2

[Step 8] Comparing image sizes...
Command: docker images
  --> my-node-app    v1    182MB
  --> my-node-app    v2    165MB (smaller due to multi-stage)
  --> Optimized image is 17MB smaller

[Verify] Docker image building working:
  --> Custom image created and tagged
  --> Container running on port 3000
  --> Multi-stage build optimization done
  --> Image size reduced from 182MB to 165MB
