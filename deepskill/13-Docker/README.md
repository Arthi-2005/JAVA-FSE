# 13 - Docker

## What is Docker?

Docker is a platform for developing, shipping, and running applications inside containers. Containers are lightweight, portable units that package your code and all its dependencies together. Unlike virtual machines, containers share the host operating system kernel.

## Why Learn Docker?

- **Consistent environments** — Works the same on your laptop, server, or cloud.
- **Lightweight** — Containers start in seconds and use less memory than VMs.
- **Isolation** — Each container runs independently.
- **Easy deployment** — Package once, run anywhere.
