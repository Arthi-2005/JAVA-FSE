=== Exercise 2: Pipeline Creation ===

[Setup] Created a Java project with Maven for pipeline demo
Project: java-web-app with pom.xml, src/main/java, src/test/java

[Step 1] Creating declarative pipeline...
Command: Edit Jenkinsfile in project root:
pipeline {
    agent any
    tools {
        maven 'Maven-3.9.0'
        jdk 'JDK-17'
    }
    stages {
        stage('Checkout') {
            steps {
                git branch: 'main',
                    url: 'https://github.com/student/java-web-app.git'
            }
        }
        stage('Build') {
            steps {
                sh 'mvn clean compile'
            }
            post {
                success {
                    echo 'Build completed successfully!'
                }
                failure {
                    echo 'Build failed!'
                }
            }
        }
        stage('Test') {
            steps {
                sh 'mvn test'
            }
        }
        stage('Package') {
            steps {
                sh 'mvn package'
            }
        }
    }
}

  --> Build: [INFO] BUILD SUCCESS

[Step 3] Adding environment variables...
Command: Added environment section:
environment {
    APP_VERSION = '1.0.0'
    BUILD_TIMESTAMP = timestamp()
}

[Step 4] Adding post-build actions...
Command: Added post section:
post {
    always {
        archiveArtifacts artifacts: 'target/*.jar'
        junit 'target/surefire-reports/*.xml'
    }
    success {
        echo 'Pipeline completed successfully!'
    }
    failure {
        echo 'Pipeline failed. Check logs for details.'
    }
}
