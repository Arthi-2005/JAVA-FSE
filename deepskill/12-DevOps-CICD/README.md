# 12 - DevOps & CI/CD

## What is DevOps?

DevOps is a set of practices that combines software development (Dev) and IT operations (Ops). It aims to shorten the development lifecycle and deliver high-quality software continuously. CI/CD (Continuous Integration / Continuous Deployment) automates the process of building, testing, and deploying code.

## Why Learn DevOps?

- **Automate everything** — Reduce manual work and human errors.
- **Faster delivery** — Release features to users more frequently.
- **Quality assurance** — Automated tests run on every change.
- **Collaboration** — Developers and operations work together seamlessly.
