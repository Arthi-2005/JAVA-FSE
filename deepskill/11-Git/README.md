# 11 - Git

## What is Git?

Git is a distributed version control system that tracks changes in source code during software development. It allows multiple developers to collaborate on the same project simultaneously without overwriting each other's work.

## Why Learn Git?

- **Track changes** — Every change is recorded with a timestamp and author.
- **Collaborate safely** — Work on features in isolation using branches.
- **Revert mistakes** — Go back to any previous version of your code.
- **Code review** — Team members can review changes before merging.
