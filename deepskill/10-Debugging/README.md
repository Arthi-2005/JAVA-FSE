# 10 - Debugging

## What is Debugging?

Debugging is the process of identifying and removing errors from software code. When your program doesn't work as expected, debugging helps you find where things went wrong. Modern IDEs like Eclipse, IntelliJ, and VS Code provide powerful debugging tools.

## Why Learn Debugging?

- **Find bugs faster** — Instead of adding print statements, use breakpoints to pause execution and inspect variables.
- **Understand code flow** — Step through code line by line to see exactly what happens.
- **Inspect variables** — Watch how variable values change during execution.
- **Fix logic errors** — Catch issues that don't cause crashes but produce wrong results.

- Java Development Kit (JDK) installed

- Basic Java programming knowledge
