# Exercise 02 — Scrum Framework

## Objectives

- Understand Scrum roles, artifacts, and events
- Differentiate between Product Backlog and Sprint Backlog
- Know what a Scrum Master does

## Scrum Roles

| Role | Responsibility |
|------|---------------|
| **Product Owner** | Defines product vision, manages Product Backlog, prioritizes features |
| **Scrum Master** | Facilitates Scrum events, removes impediments, coaches the team |
| **Development Team** | Self-organizing, builds the product increment each sprint |

## Scrum Artifacts

| Artifact | Description |
|----------|-------------|
| **Product Backlog** | Ordered list of everything needed in the product (user stories) |
| **Sprint Backlog** | Selected backlog items for the current sprint + plan to deliver them |
| **Increment** | The sum of all completed backlog items at the end of a sprint |

## Scrum Events (Time-boxed)

| Event | Duration | Purpose |
|-------|----------|---------|
| Sprint Planning | 2-4 hours (2-week sprint) | Decide what to deliver in the sprint |
| Daily Scrum | 15 minutes | Sync on progress, plan next 24 hours |
| Sprint Review | 1-2 hours | Demonstrate completed work to stakeholders |
| Sprint Retrospective | 1-1.5 hours | Reflect on the sprint and improve processes |

## Practice Tasks

1. Draw a diagram showing how Scrum roles, artifacts, and events connect.
2. Write 3 example user stories for a simple to-do app using the format: "As a <role>, I want <feature> so that <benefit>".
3. Explain in 2-3 sentences what a Scrum Master does differently from a Project Manager.
