# Exercise 04 — Agile Ceremonies

## Objectives

- Understand each Agile ceremony's purpose
- Learn how to run effective meetings
- Practice retrospective techniques

## Daily Standup (Daily Scrum)

**Time:** 15 minutes, same time and place every day.

**Each team member answers:**
1. What did I do yesterday?
2. What will I do today?
3. Are there any blockers/ impediments?

**Tips:** Don't dive into problem-solving during standup — discuss after.

## Sprint Review

**Time:** 1-2 hours at the end of each sprint.

**Agenda:**
1. Product Owner reviews what was completed vs backlog.
2. Team demonstrates working software.
3. Stakeholders give feedback.
4. Product Owner updates backlog based on feedback.

## Sprint Retrospective

**Time:** 1-1.5 hours after Sprint Review.

**Purpose:** Inspect how the last sprint went and create a plan for improvements.

**Common format — Start/Stop/Continue:**
- **Start doing:** What should we start doing?
- **Stop doing:** What's not working?
- **Continue doing:** What works well?

## Backlog Refinement (Grooming)

**Time:** 1 hour per week (not always counted as a ceremony).

**Activities:**
- Split large stories into smaller ones.
- Add acceptance criteria.
- Re-prioritize based on feedback.
- Estimate unestimated stories.

## Practice Tasks

1. Write a sample daily standup script for a team of 3 (yourself and 2 imaginary teammates).
2. Run a mock retrospective using "Start/Stop/Continue" for a fictional sprint.
3. List 3 signs that a daily standup is not working well.
