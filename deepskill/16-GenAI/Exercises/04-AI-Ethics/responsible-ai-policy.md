# Responsible AI Usage Policy

## Purpose

This policy outlines guidelines for using Generative AI tools (ChatGPT, GitHub Copilot, etc.) in our organization to ensure ethical, safe, and productive use.

## Core Principles

1. **Human Oversight** — All AI-generated content must be reviewed by a human before use.
2. **Transparency** — Disclose when content is AI-generated (code, documentation, etc.).
3. **Privacy** — Never share sensitive/proprietary data with public AI tools.
4. **Accountability** — Developers are responsible for code quality, even when AI-assisted.
5. **Fairness** — Review AI outputs for bias, especially in user-facing content.

## Guidelines

### DO
- Use AI to generate boilerplate code and tests
- Use AI to explore alternative approaches to problems
- Use AI to debug and explain errors
- Review and test all AI-generated code
- Use enterprise-grade AI tools with data privacy guarantees

### DON'T
- Copy AI-generated code without understanding it
- Share customer data, passwords, or API keys with AI tools
- Rely on AI for security-critical logic
- Use AI to generate code in regulated areas without review
- Assume AI output is always correct

## Reporting Concerns

If you encounter biased, harmful, or concerning AI output:
1. Document the output (screenshot/text)
2. Notify your team lead
3. Report to the AI Governance committee

## Review Cycle

This policy will be reviewed quarterly and updated as AI technology evolves.
